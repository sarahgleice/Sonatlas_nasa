# Geometria da Região Nacional: Amazônia Central

- **Status da Geometria:** Caixa Delimitadora Preliminar de Referência (Bounding Box).
- **Vértices (WGS84):**
  - Latitude Sul: -4.0° a -1.5°
  - Longitude Oeste: -61.5° a -58.5°
- **Área Geográfica:** Bacia do Rio Negro / Confluência com Solimões, entorno da Reserva ZF2 e Torre ATTO (Manaus, Amazonas, Brasil).
- **Finalidade:** Utilizada pelo script de corte espacial (`spatial clipping`) do pipeline Python para isolamento das células da matriz IMERG 0.1°x0.1°.

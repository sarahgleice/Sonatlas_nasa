# processing/data/raw

Este diretório é reservado para os arquivos brutos baixados da NASA Earthdata GES DISC (formatos HDF5 `.h5` ou NetCDF `.nc4`).

Arquivos brutos são ignorados pelo `.gitignore` para evitar commit de grandes volumes binários no Git.
Consulte a documentação em `docs/science/data-sources.md` para instruções de download.

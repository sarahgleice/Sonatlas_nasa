# frontend/public/visualizations

Este diretório armazena referências visuais oficiais sincronizadas com os passos temporais (por exemplo, imagens raster exportadas do NASA Earth Information Center - EIC).

Conforme estabelecido nas regras científicas do SONATLAS, os quadros visuais só são vinculados à série temporal após validação formal de correspondência e sincronização de grânulos.
